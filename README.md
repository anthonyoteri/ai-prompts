# AI Prompts Repository

This repository contains a collection of AI prompts designed for Copilot and similar tools. Each prompt is organized in its own directory at the root of the repository.

## Index of Prompts

| Prompt Directory                | Description                                      | Usage Guide                      |
|---------------------------------|--------------------------------------------------|----------------------------------|
| document-cargo-repository       | Document a Rust Cargo repository                  | [README](./document-cargo-repository/README.md) |

## How to Use

1. Browse the prompt directories listed above.
2. Each prompt directory contains an `index.md` file with the main prompt and a `README.md` with usage instructions.
3. When running a prompt, specify `{OUTPUT_FOLDER}` to set the output location for generated files (e.g., `/docs/architecture.md`).

## Contributing

- Add new prompts in a uniquely named directory at the root.
- Include an `index.md` for the prompt and a `README.md` for usage instructions.
- Follow repository guidelines and best practices as described in `.github/copilot-instructions.md`.
